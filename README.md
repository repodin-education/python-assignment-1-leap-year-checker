# Karkausvuositarkistin · Skottårskontroll · Leap Year Checker

Python-ohjelmointi 1 · tehtävä 1 · uppgift 1 · assignment 1

## Suomeksi: Karkausvuositarkistin

### Tehtävä

Kirjoita ohjelma, joka lukee vuosiluvun ja kertoo, onko se karkausvuosi. Vuosi on karkausvuosi, jos se on jaollinen 400:lla. Muuten vuosi ei ole karkausvuosi, jos se on jaollinen 100:lla. Muuten vuosi on karkausvuosi, jos se on jaollinen 4:llä.

### Syöte

Yksi kokonaisluku: vuosi.

### Tuloste

Täsmälleen `Leap year` tai `Not a leap year`.

### Esimerkit

Syöte 1:

```text
2024
```

Tuloste 1:

```text
Leap year
```

Syöte 2:

```text
1900
```

Tuloste 2:

```text
Not a leap year
```

Syöte 3:

```text
2000
```

Tuloste 3:

```text
Leap year
```

### Työskentely

Kirjoita ratkaisu tiedostoon `main.py`. Testaa ohjelma esimerkkisyötteillä komennolla `python3 main.py`, commitoi kun jokin osa toimii ja pushaa viimeisin versio GitHubiin ennen palautusaikaa.

## In English: Leap Year Checker

### Task

Write a program that reads a year and tells whether it is a leap year. A year is a leap year if it is divisible by 400. Otherwise it is not a leap year if it is divisible by 100. Otherwise it is a leap year if it is divisible by 4.

### Input

One integer: the year.

### Output

Exactly `Leap year` or `Not a leap year`.

### Examples

Input 1:

```text
2024
```

Output 1:

```text
Leap year
```

Input 2:

```text
1900
```

Output 2:

```text
Not a leap year
```

Input 3:

```text
2000
```

Output 3:

```text
Leap year
```

### How to work

Write your solution in `main.py`. Test the program with the example inputs using `python3 main.py`, commit whenever a part works, and push the latest version to GitHub before the due date.
